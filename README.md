# PBa-LLM-Privacy--and-Bias-aware-NLP-in-General-and-Applied-to-AI-based-Recruitment
fficial code and resources for "PBa-LLM: Privacy- and Bias-aware NLP", a NER-based framework for anonymizing sensitive text (names, locations, organizations) for privacy-preserving LLM training. Includes evaluation across 8 anonymizers, 6 datasets, and a bias-aware AI recruitment case study on FairCVdb.
